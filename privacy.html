Privacy Policy

Last updated: October 2026

Overview

CloudSaves is a personal utility that uses Rclone to back up game save files to the owner's Google Drive account.

Google Drive Access

The application requests Google Drive access to upload, organize, retrieve and manage game save backups.

Data Storage

Game save files are stored in the user's own Google Drive account. OAuth credentials are stored locally on the user's computer.

Data Sharing

CloudSaves does not sell or share Google user data with third parties.

Data Retention

Backups remain in Google Drive until the user removes them.

Access Revocation

Users can revoke access through their Google Account security settings.
